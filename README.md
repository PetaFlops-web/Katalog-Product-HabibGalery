# 🛍️ Frontend Ecommerce Project

## Overview

Frontend ecommerce website built with modern UI approach. Focus on
product browsing, filtering, cart interaction, and responsive design.
Intended as portfolio-ready frontend architecture baseline.

---

## ✨ Features

- Product listing with search & category filter
- Modal product preview
- Cart interaction UI
- Notification panel UI
- Responsive navigation
- Pagination support
- Tailwind CSS styling

---

## 🏗️ Tech Stack

- HTML / CSS / JavaScript
- Tailwind CSS
- Font Awesome Icons
- JSON-based product data

## ⚙️ Setup Instructions

### 1. Clone Repository

    git clone <repo-url>
    cd project-folder

### 2. Run Locally

Open HTML directly or use local server:

    npx serve .
